# Update list for the LineageOS Updater (cityman)

`cityman.json` is the list of builds that the Updater app of the Lumia 950 XL Android 16 ROM reads
(`lineage.updater.uri` in `product.prop` of the `lineage-23-cityman` branch). It is written by
`tools/updater-json.py` of that branch from the zip attached to each release, in the API v2 format of
the LineageOS 23 Updater. The Updater offers a build that is newer than the one running.

This branch holds only these two files. See "Updates from the Updater app" in `README-cityman.md` of
the `lineage-23-cityman` branch.
